## Examples

### `abs`

`abs` returns the absolute value of a number. Use it when a signed delta should
be compared by magnitude only.

<PlaygroundExample dir={require.context('../_examples/numbers/abs/normalize-delta')} />

### `ceil`, `floor`, and `round`

These functions convert fractional numbers to whole numbers. Capacity and
quota policies often need a stable integer before comparing against a limit.

<PlaygroundExample dir={require.context('../_examples/numbers/round/quota-units')} />

### `min` and `max`

`min` and `max` pick the smallest or largest value from a list of numbers.
They are a concise way to clamp a requested size into an allowed range.
